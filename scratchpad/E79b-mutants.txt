the file is restored, and the tree is checked clean afterwards.

and the corrected runs are appended below.** Run 1 compared bare test names against the
fully-qualified paths `--lib` prints (so M1 and M7 read as "did not fire" while the failing-test list

stopped after the first failing binary and two of the three named targets never RAN — which is not
evidence either way. Both are fixed in `run_mutants.py`, which now matches by suffix and refuses a
run where a named target produced no result line at all.
