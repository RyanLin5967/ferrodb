THE SHAPE, AND THE CAVEAT IN THE SAME SENTENCE
  len B/branch converges DOWN to exactly PAGE_SIZE (4104 -> 4096) as the fixed per-branch
  record cost amortises, and pages live == N throughout: each writing branch holds exactly
  one real page and pays one page of file for it. This is a SHAPE (per-branch space is O(1)
  in the number of branches, and the unit is the page) and it transfers to any engine that
  allocates extents per branch; it is NOT a BranchBench result and NOT a comparison against
  Dolt or Postgres -- a favourable absolute here would be an artifact of what ferrodb lacks.
