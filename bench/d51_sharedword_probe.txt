D51 SHARED-WORD PROBE — the premise option C rests on, measured before building on it
=====================================================================================
[HERE] this session, 18-core box, release, load ~5.4 at launch.

SCALE-DESIGN D51 chose option C over A and B on one sentence: "a shared LOAD does not bounce a
cache line -- only an RMW does." The entry itself flagged that as ASSUMED, not measured. D49 had
measured the RMW side on a real engine; the load side had no number anywhere. Building on an
unmeasured premise is the exact move D48 punished, so it is measured here FIRST.

Three arms, identical but for one operation on a word every thread shares. Prediction recorded
in the harness source before the run: LOAD scales, ARC and RWLOCK do not.

RESULT, and both arm orders agree:

ABSOLUTE at 16 threads: LOAD 3,347,527,176 ops/s against RWLOCK 6,828,543 -- 490x apart.

WHAT IS NOW SETTLED
-------------------
* Option C's foundation HOLDS. A shared relaxed load scales x7.8 on 18 cores.
* Option A (RwLock<Catalog>, readers take .read()) is MEASURED DEAD at x0.121 -- it was already
  rejected on D49's turso evidence, and this is the same verdict from an independent instrument.
* Option B (Arc::clone per statement) is MEASURED DEAD at x0.137. The refcount RMW is the whole
  cost, exactly as the entry argued.

THE AGREEMENT THAT MATTERS
--------------------------
D49 measured turso's per-statement SHARED read-mark lock at x0.308 total at 16 threads, on a real
engine doing real work. A bare RwLock::read here measures x0.121 with no work at all. Same shape,
same direction, two completely different instruments. The microbenchmark did not discover the
wall -- it confirms that what D49 found in turso is the primitive's behaviour and not turso's.

THE ARM-ORDER ROTATION FOUND NO BIAS THIS TIME, WHICH IS ALSO A RESULT
----------------------------------------------------------------------
1T absolutes, forward vs reversed: LOAD 427,903,837 / 418,668,156; ARC 165,594,234 / 147,280,649;
RWLOCK 56,518,894 / 53,070,870. D50's arms differed 2.2x for identical work; these do not. A
rotation that reports "no bias" is doing its job, and is why the D50 result needed it and this
one did not.
