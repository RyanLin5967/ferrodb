⭐ THE ABLATION NEEDS NO PATCH TO TURSO, which is why arm D is still measuring the
   real engine. core/vdbe/execute.rs:4562 reads:

       if pager.holds_read_lock() {
           ... continue;          // skip begin_read_tx entirely
       }
       pager.begin_read_tx()?;

   so one open read transaction per reader removes the PER-STATEMENT snapshot
   acquisition and changes nothing else: same Database, same buffer-pool arena, same
   WAL file, same IO, same connection count. The private-Database control could not
   do this — it duplicated every shared structure at once, so it proved that SOME
   shared structure was the wall and could not say which.

⚠ Arm D is an ABLATION, NOT A FIX. Holding a read transaction open freezes the
   reader's snapshot, so it no longer observes concurrent commits. It is here to
   establish causation, and it must never be quoted as a turso configuration.
