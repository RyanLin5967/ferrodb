Commit c6d0164 added four tests to replace that coverage. Four tests that pass prove nothing on
their own, so each was run against a mutant of the code it claims to pin. A test that does not
fail against the defect it names is not coverage.

METHOD: apply one mutant to the SOURCE (never to a test), run the named tests, revert with
`git checkout -- <file>` from commit c6d0164, apply the next. Nothing else differs between runs.
